Web-based simulation and analysis of biological models.

## Features

- Create and edit models using Antimony (https://github.com/sys-bio/antimony)
- Run time course, steady state, and parameter scan simulations
- Data visualization with 2D and 3D line charts, bar charts, and tables
- Search and pull models from the BioModels repository (https://biomodels.org)
- Sliders for interactively manipulating models
- Get help with AI assistant

Try it out now! https://sys-bio.github.io/WebIridium/
